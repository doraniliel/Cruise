# ערב פוקר 🃏

אפליקציית ניהול לערב הפוקר השבועי — מחליפה את הגוגל-שיטס.
PWA בעברית מלאה (RTL), מותקנת למסך הבית, עובדת גם בלי אינטרנט.

## מה יש בפנים

- **ניהול ערב משחק** — פתיחת משחק, בחירת שחקנים, כל שחקן מתחיל בכניסה אחת (₪30).
- **מעקב כניסות** — כפתור `+` גדול לכל שחקן, ביטול בטעות עם `−`, תקרת רי-באי (12) עם אפשרות חריגה.
- **חישוב פרסים אוטומטי** — קופה = כניסות × ₪30; חלוקה 65% / 25% / 10%; דמי בית ₪30 לשחקן; מאזן אישי לכל שחקן. הכול ניתן לשינוי בהגדרות.
- **שעון בליינדים** — מסך מלא לטלוויזיה/טאבלט: 10/20 ← 20/40 ← 30/60 ← ... עם הפסקה, גונג, הכרזה קולית, אזהרת דקה אחרונה, השהיה/דילוג, והמסך לא נכבה. מציג גם את שתי הרמות הבאות, צ'יפ ממוצע וזמן משחק.
- **מסך טלוויזיה ייעודי** — הכתובת `?tv=1` נפתחת ישר על השעון, בלי כניסה, בלי תפריט ובלי כפתורים. המסך מוצא לבד משחק שנפתח, ומציג לסירוגין פאנל מידע (חלוקת פרסים, מוביל העונה, MVP, הבאבל בוי האחרון).
- **שיתוף לוואטסאפ** — הודעת סיכום מוכנה בלחיצה אחת.
- **היסטוריה + הזנת משחקים ישנים** — כדי שהסטטיסטיקות יהיו מלאות מהיום הראשון.
- **טבלת כל הזמנים + עונות** — מאזן מצטבר, זכיות 🥇🥈, שיאים. אפשר לפתוח עונה: הטבלה מקבלת לשונית «עונה» לצד «כל הזמנים», וסגירת עונה מכתירה אלוף ושומרת אותו ברשימת אלופי העונות.
- **פרופיל שחקן** — כינוי, תמונת פרופיל, גרף רווח מצטבר, אחוז סיומים בכסף, ממוצע לערב, רצף חם/קר והשוואת ראש-בראש מול כל שחקן אחר.
- **ייצוא** — גיבוי JSON מלא, וגם CSV לגיליון (שורה לכל שחקן בכל משחק).

## כניסה והרשאות

שלושה תפקידים:

- **שחקן** — נכנס עם שם בלבד. רואה משחק חי, שעון, טבלה ופרופילים, ולא יכול לשנות כלום.
- **דילר** — נכנס עם **קוד דילר** (הגדרות ← קוד דילר, אצל המנהל). יכול להוסיף ולבטל כניסות, לצרף שחקנים ולהפעיל את השעון — כדי שהמנהל לא יצטרך לקום באמצע יד. **לא** יכול לסיים משחק, למחוק, לערוך, לפתוח משחק חדש או לשנות הגדרות.
- **מנהל** — שם משתמש + סיסמה. הכול פתוח בפניו.

אכיפת הכתיבה היא **בצד השרת**, לא רק הסתרה של כפתורים:

- כל שמירה לענן נושאת מפתח שנבדק מול `ADMIN_PASSWORD` ב-Netlify.
- קוד הדילר **נגזר** מסיסמת המנהל (`sha256('pn-dealer|' + password)`, 12 תווים ראשונים), כך שאפשר לחלק אותו בלי לחשוף את הסיסמה. שינוי הסיסמה מחליף אוטומטית את הקוד.
- מכשיר שנכנס עם קוד דילר יכול לשנות **רק** כניסות, מושבים ושעון של משחק שכבר פעיל, ולהוסיף שחקנים חדשים. כל שאר השדות מוחזרים מהעותק ששמור בשרת — גם אם ישלח בקשה מזויפת.

## אירוח ב-Netlify

1. מחברים את הריפו ל-Netlify (Import from Git). אין build command; publish = root.
2. **Site configuration → Environment variables** → מוסיפים `ADMIN_PASSWORD` עם סיסמת המנהל. בלי זה — הסנכרון לענן ידחה כל שמירה.
3. כל push ל-`main` נפרס אוטומטית.
4. פותחים את הכתובת בנייד → "הוספה למסך הבית".

## איך הסנכרון עובד?

- האפליקציה **local-first**: ערב המשחק רץ כולו מהמכשיר — טיימר וכניסות לא תלויים ברשת.
- מכשיר המנהל דוחף כל שינוי לענן (Netlify Function + Blobs); מכשירי החברים מושכים עדכונים כל כמה שניות — כולם רואים את אותם משחק, קופה, שעון וטבלה.
- כל שמירה נושאת את מספר הגרסה שעליה נערכה. אם מישהו אחר כתב קודם — השרת מחזיר את העותק שלו, המכשיר ממזג ושולח שוב. ככה שני מכשירים יכולים לספור כניסות באותו ערב.
- **נורית סנכרון** בכל מסך: ירוק = נשמר, כתום = ממתין, אדום = אופליין או שהשרת סירב. לחיצה עליה פותחת פרטים.
- מכשיר שרץ על גרסה ישנה מקבל **פס «יש גרסה חדשה»** ומרענן — אחרי שפעם אחת בנייה ישנה שמורה במטמון דרסה תוצאות של משחק שהסתיים.
- בהגדרות יש **ייצוא/שחזור גיבוי** (JSON) ו**ייצוא CSV** — ליתר ביטחון.
