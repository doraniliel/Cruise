# ערב פוקר 🃏

אפליקציית ניהול לערב הפוקר השבועי — מחליפה את הגוגל-שיטס.
PWA בעברית מלאה (RTL), מותקנת למסך הבית, עובדת גם בלי אינטרנט.

## מה יש בפנים

- **ניהול ערב משחק** — פתיחת משחק, בחירת שחקנים, כל שחקן מתחיל בכניסה אחת (₪30).
- **מעקב כניסות** — כפתור `+` גדול לכל שחקן, ביטול בטעות עם `−`, תקרת רי-באי (12) עם אפשרות חריגה.
- **חישוב פרסים אוטומטי** — קופה = כניסות × ₪30; חלוקה 65% / 25% / 10%; דמי בית ₪30 לשחקן; מאזן אישי לכל שחקן. הכול ניתן לשינוי בהגדרות.
- **שעון בליינדים** — מסך מלא לטלוויזיה/טאבלט: 10/20 ← 15/30 ← 20/40 ← ... עם הפסקה, גונג, הכרזה קולית, אזהרת דקה אחרונה, השהיה/דילוג, והמסך לא נכבה.
- **שיתוף לוואטסאפ** — הודעת סיכום מוכנה בלחיצה אחת.
- **היסטוריה + הזנת משחקים ישנים** — כדי שהסטטיסטיקות יהיו מלאות מהיום הראשון.
- **טבלת כל הזמנים** — מאזן מצטבר, זכיות 🥇🥈, שיאים.
- **פרופיל שחקן** — כינוי + תמונת פרופיל.

## כניסה והרשאות

- **שחקן** — נכנס עם שם בלבד, רואה הכול (משחק חי, שעון, טבלה, היסטוריה) אבל לא יכול לשנות כלום.
- **מנהל** — שם משתמש + סיסמה. רק מנהל פותח משחקים, מוסיף כניסות, מזין משחקים ישנים ומשנה הגדרות.
- אכיפת הכתיבה היא **בצד השרת**: כל שמירה לענן דורשת את סיסמת המנהל, שנבדקת מול משתנה סביבה ב-Netlify.

## אירוח ב-Netlify

1. מחברים את הריפו ל-Netlify (Import from Git). אין build command; publish = root.
2. **Site configuration → Environment variables** → מוסיפים `ADMIN_PASSWORD` עם סיסמת המנהל. בלי זה — הסנכרון לענן ידחה כל שמירה.
3. כל push ל-`main` נפרס אוטומטית.
4. פותחים את הכתובת בנייד → "הוספה למסך הבית".

## איך הסנכרון עובד?

- האפליקציה **local-first**: ערב המשחק רץ כולו מהמכשיר — טיימר וכניסות לא תלויים ברשת.
- מכשיר המנהל דוחף כל שינוי לענן (Netlify Function + Blobs); מכשירי החברים מושכים עדכונים כל כמה שניות — כולם רואים את אותם משחק, קופה, שעון וטבלה.
- מומלץ לנהל את הערב **ממכשיר מנהל אחד** (הדחיפה האחרונה מנצחת).
- בהגדרות יש גם **ייצוא/שחזור גיבוי** (קובץ JSON) — ליתר ביטחון.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — עיצוב, לוגיקה, שעון, סנכרון |
| `netlify/functions/state.mjs` | ה-API: קריאה חופשית, כתיבה למנהל בלבד |
| `netlify.toml`, `package.json` | הגדרות Netlify ותלות `@netlify/blobs` |
| `manifest.json` | הגדרות PWA (התקנה למסך הבית) |
| `service-worker.js` | עבודה אופליין |
| `icon-*.png`, `apple-touch-icon.png` | אייקונים |
| `PLAN.md` | מסמך האפיון המלא |
